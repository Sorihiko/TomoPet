              说话

              她用什么方式说、多久说一句、一天最多说多少。

              怎么说

              osu! 用「全屏独占」时，本地的字幕和桌面角色都盖不上去（声音照常）。录制 / 直播里的角色和字幕靠 OBS 那一份，不受影响。

              说多少

              开局、打完、失败那几句不占「每首最多几句」。

              难段预告

              开图时读这张图的 .osu，找出明显比别处难的长串、大跳、先串后跳 / 先跳后串、变速，在它前面三四秒用一句话提醒（比如「后面先跳一阵，跳完马上接串」），桌面角色和 OBS 里冒气泡，配好了「语音」就念出来。

              模型

              她每说一句话，都是这里配的模型写的。

              Key 只存在这台电脑上，只发给你填的那个接口地址。Anthropic 不用填接口地址（走代理时才填）。

              语音 可选

              她念出来用哪家的合成。不想要声音就不用填，「说话」页别开「念出来」。

              用哪家

              切换马上生效；两家合成过的句子都存在本机，同一句话不会重复花额度。

              火山引擎「豆包语音」

              Breeze TTS 2（BreezeBlue 云端）

              到 breezeblue.ai 注册登录，在 Developer → API Keys 生成 Key（brz_ 开头）。免费档每天要在网站上领一次额度，大约够念 2000 个汉字；合成过的句子存在本机，不会重复花。服务器在境外，网络不好时会超时，那一句只出字。免费档生成的声音不能商用（TomoPet 本来就不商用）。

              会念一句带小数和百分号的话，顺便听数字念得对不对。

              先开 tosu，再开 OBS。OBS 打开时 tosu 还没开的话，这两页会加载失败，之后 tosu 开了也不会自己出来（OBS 不会重试）。 出不来时不用重新添加：在 OBS 里打开这个浏览器源的「属性」，点最下面的「刷新当前页面的缓存」就行。
