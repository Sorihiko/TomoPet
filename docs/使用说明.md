# TomoPet 使用说明

> 这是完整的说明（安装、设置、OBS、皮肤、什么时候说话、难段预告、出问题时怎么办、开发）。项目首页见 [README](../README.md)。
>
> 以前叫 osu-pet（2026-11-20 改名，项目文件夹也从 `D:\Projects\osu-pet` 改成了 `D:\Projects\TomoPet`）。
> 数据目录 `%APPDATA%\osu-pet\`、日志文件名这些内部名字没改（改了的话已经填好的设置就找不到了）。

你打 osu! 的时候，她坐在旁边看，在关键时刻说一句：开局点评这张图、连击过关口、断连、突然掉准度、休息段、多人房里超人 / 被超、重开好几次、打完、失败。

- **本地**：屏幕下方一行字幕，或桌面角色头顶冒气泡，可以同时念出来。
- **OBS**：角色（会张嘴）+ 气泡 / 字幕，作为浏览器源叠在录制 / 直播画面上。
- 她「看」到的是对局数据（歌名、难度、星数、mod、准确率、连击、miss、评级），由 [tosu](https://github.com/tosuapp/tosu) 从 osu! 读出来；不是看画面。

不依赖别的程序：模型和语音都用你自己填的 API Key，设置和数据都在它自己的数据目录里。

```
osu! ──内存──▶ tosu（你自己装）──ws://127.0.0.1:24050──▶ TomoPet
                                                          ├─ 本地字幕窗口（一行字 + 声音）
                                                          ├─ 桌面角色窗口（张嘴 / 气泡）
                                                          └─ 写 tosu 的 static/fatfish-osu/state.json ──▶ OBS 浏览器源
```

## 1. 要准备什么

| 东西 | 说明 |
|---|---|
| Windows 10 / 11 | 只在 Windows + osu!stable 上验过 |
| [Node.js](https://nodejs.org/) 20 以上 | 装依赖和启动用 |
| [tosu](https://github.com/tosuapp/tosu/releases) | 第三方工具。下载 `tosu.exe` 放到随便一个**普通文件夹**（不要放 Program Files，那里写不进去），双击运行。它开着时浏览器打开 <http://127.0.0.1:24050> 能看到它的页面 |
| 一个模型的 API Key | OpenAI 兼容的接口（DeepSeek、通义、Kimi、OpenRouter、本地 Ollama…）或 Anthropic（Claude） |
| （可选）火山引擎「豆包语音」的 App ID / Access Key / 音色 ID，或者 BreezeBlue 的 API Key | 想听她念出来才需要，两家二选一 |

## 2. 安装和启动

**拿到的是打包好的 `TomoPet-<版本>-win-x64.zip`**：解压到随便一个普通文件夹，双击里面的 `TomoPet.exe` 就行（不用装 Node.js）。
CrossPet 的 15 套角色都在里面。授权看包里的「授权说明.txt」。

**从源码跑**（开发、或者自己打包）：

```powershell
cd D:\Projects\TomoPet
npm install
npm start
```

- `npm install` 会下载 Electron（约 100MB）。下载失败或很慢时换镜像再装一次：

  ```powershell
  $env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"; node node_modules/electron/install.js
  ```

- `npm start` 第一次会先把角色的渲染层打包（`dist/`），之后直接启动。也可以双击 `start.bat`（开着一个命令行窗口，关掉它程序也退出）。
- 启动后它待在**托盘**（右下角的图标）：左键打开设置，右键有开关、显示 / 隐藏角色、让她说一句试试、退出。
- 打开程序就会显示设置窗口；关掉窗口它照样在托盘里运行。带 `--hidden` 启动时只待在托盘（还没填模型 Key 时照样打开设置）。
- **自动更新**：设置「高级」→「启动和更新」。打开「自动检查更新」后，打开程序时和每隔 6 小时去 GitHub 的
  [Releases](https://github.com/Sorihiko/TomoPet/releases) 看一眼（只问最新版本号，不发任何个人信息），有新版本时托盘冒一句提示、
  托盘菜单最上面多一条「更新到 x.y.z」。点「更新」：下载新版的 zip（按 GitHub 给的大小和 sha256 校验）→ 程序退出 →
  新文件盖到程序文件夹（`resources\app` 整个换成新的，失败会换回旧的）→ 自己重新打开。设置、密钥、成绩、导入的皮肤都在
  `%APPDATA%\osu-pet`，不受影响。程序文件夹要能写（别放 Program Files）；从源码跑的只提示有新版本，用 `git pull` 更新。
  关掉「自动检查更新」就不查也不提示，要查时点「检查更新」。结果写在日志里（`[update]`）。
- **开机自启**：设置「高级」→「启动和更新」里打开。开机时带 `--hidden` 启动，只待在托盘、不弹设置窗口。开没开着以系统里的为准
  （Windows 的「任务管理器 → 启动应用」里能看到、也能关）；从源码跑时注册的是 `electron.exe <程序文件夹> --hidden`。

**logo**：把你的 logo 图片存成 `assets/logo.png`，重开程序，托盘图标、窗口图标、设置页左上角都会用它。没放时托盘图标是空白的，设置的「下一步」里会提醒。

## 3. 第一次设置（设置窗口从上往下）

设置窗口最上面的「下一步」会告诉你现在还差什么，照着做就行：

1. **模型**：选接口 → 填模型名、接口地址、API Key → 点「测试」。看到「模型通了」就好。
   - OpenAI 兼容：接口地址一般以 `/v1` 结尾，比如 `https://api.deepseek.com/v1`，模型名 `deepseek-chat`。
   - Anthropic：不用填接口地址，模型名默认 `claude-opus-5-5`。
2. **人设**：填她叫什么、怎么称呼你、提到你时用他 / 她 / TA；点「打开 persona.md」写几句她是谁、怎么说话。
3. **语音**（可选）：先在「用哪家」里选火山引擎或 Breeze（云端），填那一家的东西 → 点「试听」。然后在「说话」里打开「念出来」。切换马上生效。
   - **火山**：App ID、Access Key、音色 ID。音色 ID：自己复刻的是 `S_` 开头；官方音色在火山的音色库里找（比如 `zh_female_…_bigtts`）。资源编号留空会自动选。
   - **Breeze**（[Breeze TTS 2](https://breezeblue.ai)，BreezeBlue 的云端合成，2026-11-21 加）：到 breezeblue.ai 注册登录，Developer → API Keys
     生成 Key（`brz_` 开头）填进来，点「列出官方中文音色」挑一个；「语气说明」可选（用中文写，比如「活泼的少女，语速稍快」）。
     免费档每天要在网站上领一次额度（约 2000 个汉字）；服务器在境外，网络不好时会超时（那一句只出字）；免费档生成的声音不能商用。
   - 两家合成过的句子都存在数据目录的 `tts-cache/`，同一句话不会重复花额度。数字读法（4.8 → 4点八）两家都换；「还」原样送去合成（原来给火山换成同音字「骸」，2026-11-22 按用户要求去掉了）。
4. **怎么说**：屏幕下方字幕 / 桌面角色头顶气泡 / 不出字只念。
5. 打开 tosu 和 osu!。「状态」里 tosu 变成「已连上」，点「让她说一句试试」走一遍完整链路。

API Key 用系统的加密（Windows DPAPI）存在这台电脑上，设置窗口和日志里都不显示；只会发给你填的那个接口地址。

## 4. OBS

连上 tosu 时，程序会自动把两个页面装进 tosu 的 `static` 文件夹（设置「OBS」里能看到装在哪、能「重新装进 tosu」）。

| OBS 浏览器源 | 地址 | 宽 × 高 | 是什么 |
|---|---|---|---|
| 角色 | `http://127.0.0.1:24050/fatfish-osu/` | 比如 600 × 700 | 角色本人。她开口时张嘴，头顶冒气泡 |
| 全屏字幕（可选） | `http://127.0.0.1:24050/fatfish-osu-subtitle/` | 和画布一样，比如 1920 × 1080 | 像视频字幕那样，在画面底部正中出一行白字 |

- 两个都用时，到 tosu 的页面（<http://127.0.0.1:24050>）里把角色那个 counter 的「说话时」改成「都不显示」，免得说两遍。
- 气泡 / 脚下字幕 / 字号、全屏字幕的字号和离底边多远，都在 tosu 页面里每个 counter 的设置里改。
- **脚下的 counter**（打图时的 pp 显示，原来叫「pp 环」）：打图时她站在一个圆环上，粉色那截是这首歌打到哪了，走到的那一头是一个 osu! 圆圈（开着「环上画难度曲线」时不画环，柱子 / 墙打过的部分是粉色，就是进度条，只留那个圆圈标「现在」）；环下面是 pp 和 100 / 50 / miss（`renderer/pp-ring.ts`）；
  pp 那块字有几种样子（桌面在设置「角色 → 桌面上」的「pp 那块字的样子」，OBS 在 counter 的「pp 那块字的样子」）：**黑底卡片**（默认，深灰卡片）、**浅色成绩条**（米白纸条、深色字）、**只有字**（没有底，大号 pp 在左、100 / 50 / miss 在右；字色按壁纸选浅色或深色：桌面「『只有字』的字色」，OBS「只有字的字色」），还有原来的环下面一行、沿着环弯过去。三种新样子：只有环有颜色，数字不发光、不渐变；尺寸跟着环缩放，小字最小 11 像素。
  pp 后面可以跟一个小号的「N if FC」（默认不显示；桌面「显示『xxx if FC』」、OBS「显示 if FC」里打开）：按现在的准确率，这张图全连能拿多少（tosu 的 `play.pp.fc`，打图中一直显示，算是这把的目标）。
  **环上画难度曲线**（可选，默认开）：默认连成一圈墙竖在环上（顶上一条亮线），环上每个位置对应歌的某一刻（和进度同一套走法），那一刻越难越高；
  打过的是粉色、后面的是灰色，后半圈在她身后、前半圈更透明，一眼看出后面哪里难
  （tosu 的 `performance.graph`，要 osu! 开着才有；`core/strain-curve.js`）。
  桌面在设置「角色 → 桌面上」里开关，OBS 在 tosu 里角色那个 counter 的「环上画难度曲线」。
  也可以改成**一圈柱子**：桌面在同一处的「难度曲线的样子」，OBS 在 counter 的「难度曲线的样子」。
  OBS 那份直接读 tosu 的实时数据；不想要就在 tosu 页面里角色那个 counter 的「脚下的 counter」选「不显示」。
  桌面上那份在设置「角色 → 桌面上」里开关（默认开，开着时窗口底下多留一截给环和字）。
- 换了皮肤不用动 OBS：页面会自己重载（最多等一分钟，或点「重新装进 tosu」）。
- 从 SurfCore 搬过来的：原来的两个源地址（`surfcore-xiaojingyu…`）要换成上面这两个，并且把 SurfCore 里的「看你打 osu!」关掉，不然两边都会说话。

> osu! 用「全屏独占」时（英伟达即时回放要它才会录），本地的字幕窗口和桌面角色都盖不上去，只有声音；录制 / 直播里的角色和字幕靠 OBS 这一份，不受影响。

## 5. 皮肤

程序自带 CrossPet 的 15 套角色（见下一节），默认用 DeepSeek（女仆装）。仓库里一套皮肤都没有（占位小人 2026-11-20 删了）。
别的立绘你自己放进来：

- 设置「角色」→「导入皮肤…」，选皮肤的文件夹（里面直接有 `manifest.json` 和图层）；或者点「打开皮肤文件夹」手动放进 `<数据目录>\skins\<id>\`。
- 皮肤格式：`rig: "sprite"`（一张图一个姿势，CrossPet 那种；照 `skins-bundled/` 里任意一套写）、`rig: "layered"`（feiyu-pet 的分图层立绘，
  程序做呼吸、眨眼、视线、张嘴）或 `rig: "video"`（一段段动态 AVIF）。
- 桌面角色和 OBS 里用同一套。选的皮肤有问题（缺文件、清单写错）或者没了时会说清楚哪里不对，并先换成 DeepSeek（女仆装）；
  没有 DeepSeek 就用列表里第一套。一套皮肤都没有时（从源码跑、还没放 `art/`）桌面角色和 OBS 角色都出不来，设置里会说该怎么办。

### CrossPet 的角色（推荐）

[CrossPet](https://github.com/lokicorvus/crosspet) 给 DeepSeek、Claude、GPT、Gemini、GLM、Grok、千问、Kimi 八个角色（加几套换装）各画了约 60 张姿势。
TomoPet 把它们做成**姿势皮肤**（`rig: "sprite"`）：打 osu! 时她按游戏时刻换姿势，桌面和 OBS 里都一样。

程序默认就带着全部 15 套（8 个角色 + 7 套换装），在设置「角色」→「皮肤」下拉框里直接选，不用导入：

- 图放在程序文件夹的 `art/crosspet/`（CrossPet 仓库里的 `characters` 文件夹，或者整个仓库）。
- `npm start` / `npm run build` 时把它们转成皮肤，放进 `skins-bundled/`（只拷用得上的约 20 张，一共约 33 MB）；
  转过、没变的下次跳过。手动重转：`npm run bundle-crosspet`。
- 两个文件夹都不进 git（`.gitignore`）：代码和受版权保护的立绘分开。从源码跑的人 `art/crosspet/` 要自己放
  （下载 CrossPet：GitHub 页面上 Code → Download ZIP，解压，把 `characters` 文件夹放进去）。
- **给别人的打包版自带全部 15 套**：`npm run package` 出 `release/TomoPet-<版本>-win-x64.zip`（见第 9 节），里面带转好的皮肤、
  每套的 `CREDITS.md` 和「授权说明.txt」。
- 自己数据目录里有同名的皮肤时，用数据目录里那套（以前用「导入 CrossPet 角色」按钮导进来的旧副本除外）。

| osu! 里 | 她的样子 |
|---|---|
| 开局 / 打图中 | 握拳冲一下，然后专注地看着（listening） |
| 连击过关口、多人房超人 | 开心地跳（happy） |
| 断连 | 「呜哇」，转圈眼、冒汗（oops） |
| 断在滑条上 | 吓一跳（surprised） |
| 这一断全连没了 | 晕乎乎地晃（dizzy） |
| 突然掉准度 | 不高兴（annoyed）　　被超：鼓脸（puffed） |
| 休息段 | 喝水（drink），休息段结束放下 |
| 重开 3 次 / 10 次 / 20 次以上 | 委屈（sulk）→ 累了（tired）→ 红温冒烟（redhot） |
| 全连打完 | 戴着皇冠得意（proud） |
| 打完（A 以上 / B 以下） | 开心 / 委屈 |
| 失败 | 晕（dizzy）　　中途退出：委屈 |
| 她说话时 | 刚发生的事的姿势陪着这句话摆着，整个人轻轻点头；平时就换成张嘴的 listening |
| 桌面上摸头 / 戳她 | 被摸开心；连着戳越来越生气，生气时摸头先被哄、再原谅 |
| 很久没动静 | 打哈欠，然后睡着（打图中不会困） |

- 这些图是静态的，没有张嘴的帧。说话时嘴会动（2026-11-21）：张嘴的口型取自 [hunmer/aboutme-pets](https://github.com/hunmer/aboutme-pets)
  用这些立绘生成的「碎碎念」动画，把几帧的嘴对齐到待机图上，做成只有嘴的叠加图（闭 / 半张 / 张大），按念出来的声音响度换；
  没开语音时按字数一张一合。没有对应动画的角色（DeepSeek 几套、换装）用别的角色的嘴移植。
  - 做嘴图：`python scripts/mouths/make-mouths.py`（要 Python 3 + Pillow；配置在 `scripts/mouths/mouths.json`）。动画按钉死的提交下载到
    `art/hunmer/`、核对 sha，嘴图输出到 `art/mouths/`，下次 `npm run bundle-crosspet` 时拷进皮肤。两个文件夹都不进 git。
  - 说话途中赶上游戏时刻（比如断连）时摆那个姿势，那时嘴不动。
- 姿势不想要哪个，改 `manifest.json` 的 `sprite.reactions`（时刻 → 姿势 / 动作 / 摆多久 / 优先级）。直接改 `skins-bundled/` 里的会在下次重转时被盖掉：
  把那套拷进数据目录的 `skins/` 再改（换个文件夹名，或者把 `source` 那一项删掉，不然会被当成以前导入的旧副本、让给自带的）。
- 姿势不说话也会换（说不说话还是按下面第 6 节的规则）。

**授权**：CrossPet 的立绘和设定是 CC BY-NC-SA 4.0，据它说明由 AI 生图工具按社区设定绘制。直播、录像、截图公开时请带上皮肤文件夹里
`CREDITS.md` 的署名，**不要商用**。CrossPet 的授权只覆盖它自己有权授权的部分：社区既有设定（例如 B 站 ZipZipPipe 设计的
DeepSeek「大肥鱼」、GPT、GLM、千问、Kimi、Grok）的权利以各自来源为准，公开使用前最好先问原作者。
张嘴口型来自 hunmer/aboutme-pets，同样是 CC BY-NC-SA 4.0：公开时署名「张嘴口型：hunmer/aboutme-pets」，每套用的哪段动画、改了什么写在它的 `CREDITS.md` 里。

**立绘不在这个仓库里，也不要提交进来**：feiyu-pet 的小肥鱼立绘、Claude 娘素材（[Claude-Chan](https://github.com/Ivanfangsc/claude-chan)，CC BY-NC-SA 4.0）等都有各自的版权 / 授权，只能各自从来源取得后放进自己的数据目录。`.gitignore` 挡住了仓库根下的 `skins/`。

## 6. 什么时候说、什么时候不说

| 时刻 | 规则 |
|---|---|
| 开局 | 每张图都说，点评快不快、难不难（带 BPM / AR / CS）。离上一句 6 秒就行；同一张图十分钟内退出重进不再点评 |
| 连击过 100 / 200 / 300 / 500 / … | 这个关口至少是这张图总连击数的 15% 才说 |
| 断连（含滑条断） | 断掉的那段至少是总连击数的 15%（至少 50）才说；这一断把全连断没了的，至少 50 就说 |
| 突然掉准度 | 12 秒里多出 5 个以上不准的（100 算 1 个，50 算 2 个），并且准确率掉了 0.6 个点以上 |
| 休息段 | 可以长一点、报一两个数；一首最多两次，离上一句 15 秒 |
| 多人房名次变了 | 稳住 2.5 秒才算，说得出超了谁 / 被谁超 |
| 重开 | 只在第 3 / 6 / 10 / 15 / 20 / 30 次说 |
| 打完、失败 | 一定说 |
| 中途退出 | 打过 30% 才说 |
| 看回放 / 观战 | 不说、不记 |

打的过程中的话：两句之间至少隔 10 秒、一首歌最多 10 句、一天最多 1000 句（默认值，都能改）；要求不超过 18 个字（开局和休息段 30 字，结束 40 字）。
模型写了超过 9 秒（要念出来时 16 秒）、或者写完时这一把已经结束了，这句就丢掉，不在结算后才蹦出一句「断了」。
设置「状态」里的「最近没说的」会写明某一下为什么没说。

星数、BPM、AR 都是**算上 mod 之后**的；快慢由程序按设置里「快慢的界限」判断好再告诉她（默认：BPM ≥230 很快、200–229 偏快、151–199 中等、≤150 偏慢；AR <9 偏慢、>10 偏快），可以在设置里改成你自己的手感。
难度的方向是写死的，不跟尺子走：**AR 低不等于简单**——AR 10 以下是越低越难读，10 以上才是越高越难，所以「偏慢 / 偏快」后面会直接告诉她难不难；
**EZ 是增加难度的 mod**（它把 AR 压低、圈更难读），开了 EZ 时会明确告诉她这一点，并且不让她拿星数说它简单（EZ 会把星数算低）。一场的小结里也只说「星数最高的一把」，不说「最难的一把」。
念出来时数字会换成念得对的写法（4.8 → 4点八、97.42% → 百分之97点四二、17:38 → 17点38），字幕上的文字不变。

### 难段预告（默认开）

设置「说话」→ 难段预告。开图时读这张图的 `.osu`（tosu 给的路径；读不到再问 tosu 要，按 checksum 核对是不是这张），
找出**明显比这张图别处难**的长串、大跳、先串后跳 / 先跳后串 / 串跳轮着来、变速，在它前面三四秒用一句话提醒
（`core/patterns.js` 找难段、`core/heads-up.js` 到点提醒）：

- **给我提个醒**：念一句完整的话（「后面有一段长串，准备好」「后面要开始大跳了，手放开点」「后面先跳一阵，跳完马上接串」
  「后面要变快了，跟上节奏」…），开图前就合成好放在内存里，到点直接放，不现场调模型。要先在「语音」里配好合成（火山或 Breeze 都行，不用开「念出来」）。
  桌面角色和 OBS 里她冒气泡、张嘴说这句。
- 大跳按**光标在屏幕上真的挪多远**算（osu! 坐标的像素，和 CS 无关），参照 Apollo - Brazil (moonpoint) [Fiery's Extreme] 的结尾：
  一下从上一个物件的尾巴挪 320px 以上、中间不超过 250ms；连着 6 下以上（中间最多夹一下小的），整段的中位距离到 350px、
  中位速度到每毫秒 2px 才算一段。那张图前面 240–320px 的普通跳不算，走路段也不会被叫成大跳。不按拍子卡：1/4、1/3 拍挪三四百像素一样算。
  滑条的尾巴按滑条路径和长度真算出来（`core/slider-path.js`），不拿最后一个控制点凑。
- 挨着的难段（这一段的提示会落在前一段里面时）并成一段，记住先后：先串后跳、先跳后串，三截以上就是串跳轮着来。
- **难度曲线补漏**：tosu 会给这张图的难度曲线（每 0.4 秒一段，aim / 手速 / 读图各一条）。比全图九成的段都难、连着 1.2 秒以上的算高峰：
  和认出来的难段重叠就给它加分（更容易被报）；不重叠的是规则没认出来的难处，单独报成「后面这段很考 aim / 很考手速 / 很难读」。
  只在开打前用，而且曲线要和这张图对得上（换图时 tosu 的曲线可能还是上一张的）；没开 osu! 时 tosu 不给曲线，就只按规则认。
- 提前量：「念完这句 + 1 秒反应」和「2 秒 / 4 拍取长」里取长的，最多 4.5 秒。开 DT / HT 按倍速换算。
- 每张图最多报几次（默认 8），两次至少隔 15 秒；开头 3 秒来不及报的不报；整张图都是串（串占了四成以上时间）时只报比别的串明显长、明显快的。
- 开 HD / FL、在多人房里照样报；看回放 / 观战时不报；暂停时不报，重开从头再报。难段前 6 秒到难段结束，打图中途的点评先不说。
- 串的认法：节奏连续（相邻间隔不超过 250ms、和上一下差不超过 35%，
  转盘打断），两下之间真实不超过 115ms（约 130 BPM 的 1/4 拍）、按拍子够快（不超过 1.5 个 1/4 拍）才算串。
  滑条只能在串的头尾，一串 kick 滑条不算串；红线写成一半 BPM 的图里，谱面上的「1/4 拍」其实是 1/2 拍，按真实间隔就不会被骗；
  每下挪三百多像素的不算串（那是大跳）。
- 串还分样子（定义照 osu! 官方谱面标签，门槛按本机 3 万张图的分布定），提醒的话跟着变：
  **宽间距串**（中位间距 ≥ 2.4 个圆的半径，圆和圆不挨着）、**断开的串**（节奏不断，个别几下间距远大于别的、隔得有规律，
  比如四个一组中间跳）、**叠串**（八成以上叠在一起）、**来回跳的串**（间距 ≥ 3 个半径、来回折返）。
  「一大段长串」是 65 下以上或 8 秒以上。
- **它做什么、不做什么**：只读本地的 `.osu` 文件和 tosu 给的数据（这张图本来就能在编辑器里看完）；不改缩圈快慢、不碰鼠标键盘、
  不改游戏画面。性质和直播弹幕提醒或朋友语音提醒差不多。

### 这是张什么图（玩家标签）

开局点评时，她会知道这张图是什么样的，两样来源（`core/map-info.js`）：

- **玩家标签**（可选）：osu! 官网上玩家投票加的 User Tags（比如 `tech/aim control`、`skillset/alt`、`streams/flow aim`），
  照官网的规矩只看 5 票以上的。要用你自己的 OAuth 应用：在 [osu! 官网 → 设置 → OAuth](https://osu.ppy.sh/home/account/edit#oauth)
  点「新的 OAuth 应用」，名字和回调地址随便填，把 Client ID 和 Client Secret 填进设置「高级」，点「试一下」。
  走官方 API（`client_credentials`，`core/osu-api.js`），只发谱面集编号；查过的存在 `osu-tags.json`，7 天内不再查（官网上没有的 1 天）。
  不是每张图都有：本地图、新图、没人投够票的图没有。
- **主要考什么**（tosu 算好的 aim / 手速星数，算上 mod）：aim 是手速的 1.4 倍以上说「偏 aim」，手速比 aim 高说「偏手速」，
  中间说差不多；滑条占的难度多也提一句。门槛是估的，听着不对可以再调（`core/watch.js` 的 `skillFeel`）。
- **从谱面看**（每张图都有）：串多不多、有几段长串 / 断开的串 / 宽间距串、大跳几段、有没有变速（读本地 `.osu`，和难段预告同一套认法）；
  另外两项：**滑条变速多**（25% 以上的相邻两条滑条速度差一成半以上）、
  **难读**（按算上 mod 的 AR，3% 以上的圈一出现就压着同屏别的圈；原地叠着的不算）。门槛按本机图库的分布定，只有明显偏多才说。

## 7. 数据在哪

数据目录：`%APPDATA%\osu-pet\`（设置「关于」里能打开；环境变量 `OSU_PET_HOME` 可以改到别处）。

| 文件 | 内容 |
|---|---|
| `config.json` | 全部设置（Key 是加密的）。改之前会备份到 `backups/`，留最近 10 份 |
| `persona.md` | 人设 |
| `plays.json` | 最近 60 把成绩、最近 7 天每天说了几句 |
| `summaries.json` | 一场打完后的小结（最近 20 场；15 分钟没有新的一把算一场结束）。她下次开口时会带上最近 3 场 |
| `skins/` | 你的皮肤 |
| `tts-cache/` | 合成过的语音（最近 200 句） |
| `osu-tags.json` | 查过的 osu! 官网玩家标签（按谱面集存，7 天过期） |
| `logs/osu-pet.log` | 日志（不含 Key） |

她说过的每一句话不存；tosu 的原始数据不存。发给模型的只有：人设、最近几场的小结、这一下发生了什么（一段几十字的描述）。

## 8. 出问题时

所有失败都会显示在设置窗口里（「下一步」那一块、或右下角的红色提示），带三样东西：哪里不对、现在该点什么、错误码。

| 错误码 | 意思 | 怎么办 |
|---|---|---|
| `osu.tosu-offline` | 连不上 tosu | 打开 tosu.exe，让 osu! 开着；开着的时候会自动连上 |
| `osu.no-frames` | 连上了但没有对局数据 | 打开 osu!；还不行就更新 tosu |
| `llm.no-key` / `llm.auth` / `llm.rate-limit` / `llm.timeout` / `llm.network` / `llm.http` / `llm.refused` / `llm.empty` | 模型：没填 Key / Key 被拒 / 太频繁或没额度 / 超时 / 连不上 / 服务报错 / 拒答 / 回了空的 | 设置「模型」里点「测试」看具体原因 |
| `tts.no-key` / `tts.no-speaker` / `tts.auth` / `tts.api` / `tts.timeout` / … | 语音合成的问题 | 设置「语音」里点「试听」。这一句会只出字，不会丢 |
| `osu.voice-failed` | 这一句没念出来 | 同上 |
| `osu.no-output` | 选了不出字又没开「念出来」 | 打开「念出来」或改回字幕 |
| `osu.pet-hidden` | 选了气泡，但桌面角色没显示、OBS 里的角色也没装好、又没开「念出来」（这时她不说） | 托盘菜单里点「显示角色」，或者看「OBS」那一块把角色装进 tosu |
| `osu.bubble-obs-only` | 桌面角色藏着，气泡只出在 OBS 里（只是提醒） | 想自己屏幕上也看到就打开桌面角色 |
| `osu.bubble-voice-only` | 桌面和 OBS 的角色都看不见：只出声 | 同 `osu.pet-hidden` |
| `osu.bubble-nowhere` | 这一句气泡哪边都没显示出来（OBS 那边写失败时用 `osu.counter-write`） | 看设置「角色」和「OBS」的提示 |
| `osu.other-watcher` | SurfCore 原来那只小鲸鱼最近 30 分钟也在 tosu 里说过话：两边各说一句，声音叠在一起 | 在 SurfCore 设置页「桌宠」→「看你打 osu!」里关掉；OBS 里删掉或藏起 surfcore-xiaojingyu 源 |
| `osu.counter-no-tosu` / `-bad-dir` / `-write` / `-no-renderer` | OBS 页面没装进 tosu：tosu 没开 / 目录不对 / 写不进去 / 渲染层没打包 | 设置「OBS」里看提示；写不进去时把 tosu 挪到普通文件夹 |
| `skin.*` | 皮肤有问题 | 提示里写了缺哪个文件 / 哪里写错了 |
| `overlay.failed` / `pet.*` | 字幕窗口 / 桌面角色窗口出错 | 下一句会重开窗口；一直这样把日志发给开发者 |

## 9. 开发

```powershell
npm test          # 跑全部测试（Node 内置 assert，不连真的 tosu、不调真的模型和语音）
npm run build     # 重新打包渲染层（改了 renderer/ 之后），并把 art/crosspet/ 转成 skins-bundled/
npm run bundle-crosspet    # 只重转 CrossPet 的角色
npm run package   # 打包给别人用的 Windows 版：release/TomoPet-<版本>-win-x64/ 和同名 .zip（加 -- --no-zip 只出文件夹）
```

**发新版本（让大家的程序自动更新）**：

1. 改 `package.json` 里的 `version`（比如 `0.1.0` → `0.2.0`，三段数字）。
2. `npm run package`，得到 `release/TomoPet-0.2.0-win-x64.zip`。
3. GitHub 仓库的 Releases → Draft a new release：tag 写 `v0.2.0`（和版本号一样，前面加 v），说明里写改了什么，
   把那个 zip 拖进附件，发布（别勾 pre-release，程序只看正式版）。仓库要是公开的。

大家的程序下次检查时就会提示「有新版本 0.2.0」。附件名必须是 `TomoPet-<版本>-win-x64.zip`，包里的版本号要和 tag 一致，不然程序不装。

**打包给别人**（`npm run package`）：拷一份 `node_modules/electron/dist`（`electron.exe` 改名 `TomoPet.exe`），
程序放进 `resources/app/`：`app/ core/ counter/ dist/ assets/ skins-bundled/` + 运行时依赖（`@anthropic-ai/sdk` 和它依赖的包），
最外层放「使用说明.txt」和「授权说明.txt」。不拷原图（`art/`）、渲染层源码、脚本、测试。不联网、不用额外装打包工具。
- 打包前要先放好 `art/crosspet/`：有角色没转成、或者一套都没有时不打（给别人的包要带全）。
- 包的最外层还有 `THIRD-PARTY-NOTICES.txt`：先是源码里照搬 / 改编的上游代码（SurfCore、surfpet 的 `rig.ts`、CrossPet，都是 MIT，
  全文在 `licenses/`），后面是带着的每个 npm 包（PixiJS、`@anthropic-ai/sdk` 是 Apache-2.0，等等）的协议和授权全文。
- `TomoPet.exe` 的图标换成 `assets/logo.png`（16～256 像素七个尺寸）：用 Windows 自带的 System.Drawing 缩放、系统的
  UpdateResource 写进 exe（`scripts/exe-icon.mjs`、`scripts/win/*.ps1`），不用另外装工具；写完会读回来核对。
  换完 exe 原来的数字签名（Electron 的）就失效了，第一次打开时 Windows 可能提示「未知发布者」。出问题时用 `npm run package -- --no-icon`。
- exe 的版本信息（任务管理器里的「描述」、属性里的产品名 / 公司 / 版权 / 版本号）写成 TomoPet，版本号取 package.json、版权取 LICENSE
  （`scripts/exe-version.mjs`、`scripts/win/set-exe-version.ps1`，同样用系统的 UpdateResource，写完读回来核对）。出问题时用 `npm run package -- --no-version`。
- 打包前先从托盘退出正在跑的打包版 TomoPet，不然旧文件删不掉（会提示 `package.busy`）。
- 立绘是 CC BY-NC-SA 4.0：这个包可以免费分享，不能卖；分享时带着「授权说明.txt」。

目录：


## 11. 已知的限制

- 只在 Windows + osu!stable 上验过；lazer、多人房名次、突然掉准度、休息段只在测试里验过。
- 全屏独占时本地的字幕和桌面角色看不到（声音照常），程序分辨不出来，她照样会说、照样花钱。
- 本地字幕只出在主显示器上。
- 语音合成要几秒：打图中的话会比事情发生晚几秒才出来。
- 和 SurfCore 的「看你打 osu!」同时开，两边都会说话：用一个就把另一个关掉。
